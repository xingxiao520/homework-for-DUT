1.1 Zero-填充¶

0填充用于在一张图像的周围添加0，如下图所示:

填充的作用如下:

  • 它使得一张图像在经过卷积层后的大小不发生明显变化. 这对于深层网络来说非常重要，否则当你使用深层网络后，有很多卷积层，图像的高度和宽度会缩小非常多.一个重要的使用情况是使用“same”填充，此时通过卷积层后图像的宽度和高度不会发生任何变化和上一层一样.

  • 它帮助我们保留了更多图像边缘的信息. 如果没有填充，一张图像的边缘像素对下一层计算的值影响很小，因为边缘像素相比于中间的像素点，经过的卷积操作更少.

1.2 一步卷积操作¶

本小节实现一步卷积操作，需要用一个filter对输入的每一个位置进行卷积。 构建一个卷积单元：

  • 给定一个输入图像（立体，高度、宽度、通道数）
  • 对输入的每一通道的每一个位置应用一个filter
  • 输出另一个图像（立体，高度、宽度、通道数。大小通常不一样）

在计算机视觉中，左边矩阵中的每一个值对应一个单一像素值, 我们用一个3*3的filter对输入图像进行卷积，通过把filter中的权重参数和矩阵对应位置的像素值进行相乘再求和并加上一个偏置参数，得到输出图像矩阵中的一个值. 实验的第一步是实现一步卷积操作，使用filter对其中的一个位置进行卷积得到一个实数输出

之后，将使用这个函数对输入图像的其他位置进行卷积，实现一个完整的卷积操作.

def conv_single_step(a_slice_prev, W, b):
    """
    在前一层激活函数输出的一个样本的部分区域（即一张图像的部分区域 (f,f,n_C_prev)与filter一样大）上应用一个由权重参数W定义的一个filter(f,f,n_C_prev)，
    进行卷积操作得到一个实数

    Arguments:
    a_slice_prev --输入数据中的一个样本的部分区域（即一张图像的部分区域） (f, f, n_C_prev)
    W -- filter窗口中的权重参数 - 维度(f, f, n_C_prev)
    b -- filter窗口中的偏置参数 - 维度 (1, 1, 1)

    Returns:
    Z -- 一个实数, 滑动窗口(W，b)在一个在输入数据的一个样本（一张图像）上的一步卷积操作值。
    """

    ###请输入代码###（≈ 2 line）
    #对应位置相乘
    s = a_slice_prev * W
    #对s（立体）的所有元素进行求和
    Z = np.sum(s)
    #加上偏置参数
    Z = float(b) + Z
    ###请输入代码###

    return Z

1.3 CNN - 前向传播¶

前向传播中，需要使用多个filters对输入图像（立体）进行卷积。每一个filter（立体，和输入图像的通道数相同）对输入图像（立体）进行卷积后会得到一个2维矩阵，把每个filter产生的2维矩阵堆叠起来就会得到一个立体（输出图像，通道数与filter的个数相同）

练习: 实现以下函数，对输入的上一层产生的激活函数输出A_prev(包含m个样本，即m张图像，每张图像是一个立体，A_prev是一个4维数组，(m,height,width,n_C)初始的A_prev就是训练集X）应用F个filters(f,f,n_C) W进行卷积,得到另一个四维数组(m,height',width',F),m个样本使用同一个模型分别进行计算. 函数的输入是A_prev, 上一层的激活输出 (包含m个样本), F 个filters的权重参数表示为W(f,f,n_C,F),每一个filter都有一个偏置参数，构成一个偏置参数向量b（1,1,1,F)。 最后还要使用一个包含步长和填充的超参数字典。

注意: 输入图像($n_{H_{prev}}$,$n_{W_{prev}}$,$n_{C_{prev}}$)经过卷积操作后得到的输出图像($n_H$,$n_W$,$n_C$)的大小可以用下列公式进行计算:

def conv_forward(A_prev, W, b, hparameters):
    """
    实现卷积操作的前向传播

    Arguments:
    A_prev -- 上一层激活函数的输出, 四维数组(m, n_H_prev, n_W_prev, n_C_prev)
    W -- filters的权重参数，四维数组 (f, f, n_C_prev, n_C)
    b -- filters的偏置参数，四维数组 (1, 1, 1, n_C)
    hparameters -- Python字典包含步长和填充

    Returns:
    Z -- 卷积操作后的输出，四维数组 (m, n_H, n_W, n_C)
    cache -- 缓存重要的参数，与卷积操作的反向传播共享参数
    """
    ###请输入代码###

    #得到输入的相关信息
    (m, n_H_prev, n_W_prev, n_C_prev) = A_prev.shape
    #得到filters的相关信息
    (f, f, n_C_prev, n_C) = W.shape

    #得到步长和pad
    stride = hparameters['stride']
    pad = hparameters['pad']

    #计算输出图像的高度和宽度
    n_H = int((n_H_prev - f + 2 * pad) / stride) + 1
    n_W = int((n_W_prev - f + 2 * pad) / stride) + 1

    #用0初始化卷积操作的输出
    Z = np.zeros((m, n_H, n_W, n_C))

    #对上一层激活函数的输出A_prev 进行填充
    A_prev_pad = zero_pad(A_prev, pad)

    for i in range(m):     #对输入的m个填充样本（m张图像）循环处理
        a_prev_pad = A_prev_pad[i] #取出第i个填充图像
        for h in range(n_H):  #遍历输出图像垂直方向上的每个像素点
            for w in range(n_W): #遍历输出图像水平方向上的每个像素点
                for c in range(n_C):#遍历输出图像的每个通道

                    #找到每个输入图像的各个区域

                    #垂直方向起点
                    vert_start = h * stride
                    #垂直方向终点
                    vert_end = vert_start + f
                    #水平方向起点
                    horiz_start = w * stride
                    #水平方向终点
                    horiz_end = horiz_start + f

                    #得到一个区域
                    a_prev_pad_slice = a_prev_pad[vert_start:vert_end, horiz_start:horiz_end, :]
                    #计算该区域上的卷积操作 得到某个输出图像单个通道上的一个值
                    Z[i, h, w, c] = conv_single_step(a_prev_pad_slice, W[:, :, :, c], b[:, :, :, c])

    ###请输入代码###

    assert(Z.shape == (m, n_H, n_W, n_C))

    cache = (A_prev, W, b, hparameters)

    return Z, cache

1.4 池化层¶

池化层可以缩小输入图像的宽度和高度，但不会改变输入图像的通道数. 它可以减少计算量, as well as helps make feature detectors more invariant to its position in the input. 有以下两种池化层:

  • Max-pooling layer: 在输入图像(n_H_prev,n_W_prev,n_C_prev)在滑动一个大小为(f,f,n_C_prev）的窗口，并将窗口内的最大值存储在输出图像（n_H,n_W,n_C_prev)中.

  • Average-pooling layer: 在输入图像(n_H_prev,n_W_prev,n_C_prev)在滑动一个大小为(f,f,n_C_prev）的窗口，并将窗口内的平均值存储在输出图像（n_H,n_W,n_C_prev)中.

这些池化层没有模型参数，不需要使用反向传播进行训练. 但是，他们有超参数，如窗口大小 $f$. 指定了f*f的窗口高度和宽度，就可以计算窗口中的最大值或平均值了.

def pool_forward(A_prev, hparameters, mode = "max"):
    """
    实现池化层的前向传播.

    Arguments:
    A_prev -- 输入数据，包含m张图像 四维数组 (m, n_H_prev, n_W_prev, n_C_prev)
    hparameters -- Python字典，包含超参数f和stride，池化一般没有填充
    mode -- 池化类型 max or avg

    Returns:
    A -- 池化层的输出 四维数组(m, n_H, n_W, n_C)
    cache -- 缓存重要的参数 包括输入数据和超参数 与池化层的反向传播共享参数
    """

    # 得到池化层输入数据的信息
    (m, n_H_prev, n_W_prev, n_C_prev) = A_prev.shape

    # 得到超参数f和stride
    f = hparameters["f"]
    stride = hparameters["stride"]

    # 计算输出图像的大小
    n_H = int(1 + (n_H_prev - f) / stride)
    n_W = int(1 + (n_W_prev - f) / stride)
    n_C = n_C_prev

    # 初始化池化层的输出数据 四维数组 包含m张图像
    A = np.zeros((m, n_H, n_W, n_C))

    ###请开始输入代码###

    for i in range(m): #遍历输入数据的m张图像
        for h in range(n_H):#遍历每个输出图像垂直方向上的每个像素
            for w in range(n_W):#遍历每个输出图像水平方向上的每个像素
                for c in range(n_C):#遍历每个输出图像的每个通道

                    #找到每个图像各个区域的起始点
                    vert_start = h * stride
                    vert_end = vert_start + f
                    horiz_start = w * stride
                    horiz_end = horiz_start + f

                    #得到一个区域
                    a_prev_slice = A_prev[i, vert_start:vert_end, horiz_start:horiz_end, c]

                    if mode == 'max':
                        A[i, h, w, c] = np.max(a_prev_slice)
                    elif mode == 'average':
                        A[i, h, w, c] = np.mean(a_prev_slice)

    ###输入代码结束###

    # 缓存重要参数
    cache = (A_prev, hparameters)

    assert(A.shape == (m, n_H, n_W, n_C))

    return A, cache

1.5 卷积神经网络的反向传播¶

在现代深度学习框架下，你只需要实现前向传播，框架会帮你实现反向传播。所以对于大多数深度学习工程师来说不需要关注反向传播的细节，而且CNN的反向传播过程非常复杂。如果你想了解一下，可以通过本小节的实验来对CNN中反向传播有个直观的认识。

在之前的实验中，我们曾经手动实现了简单神经网络(全联接网络）的前向/反向传播过程，通过反向传播来计算代价函数相对于每个参数的偏导数（梯度）以此来更新参数。同理，在CNN中我们也需要计算代价函数相对于每个参数的偏导数来更新参数。反向传播的方程并不琐碎，我们在课程上并没有推导他们，接下来我们简答介绍一下他们。

1.5.1 卷积层反向传播¶

我们先来实现一下卷积层的反向传播过程。

1.5.1.1 - 计算 dA:¶

对于一个给定的filter $W_c$ 和 一个给定的训练样本,下面的公式用于计算$dA$，即损失函数对A的偏导数 :

$$ dA += \sum _{h=0} ^{n_H} \sum_{w=0} ^{n_W} W_c \times dZ_{hw} \tag{1}$$

其中 $W_c$ 是一个filter， $dZ_{hw}$ 是一个标量,它是损失函数相对于卷积层的输出Z在第h行和第w列的值Z_{hw}的偏导数(corresponding to the dot product taken at the ith stride left and jth stride down). 注意每次更新dA时,我们用相同的filter $W_c$ 乘以不同的 dZ . 这样做的原理主要是因为在前向传播中, 每一个filter会和不同的a_slice对应相乘再相加. 因此，当反向传播计算dA时, 我们需要添加所有a_slice的梯度.

编程时，在适当的for循环中，这个公式可以这样实现：

da_prev_pad[vert_start:vert_end, horiz_start:horiz_end, :] += W[:,:,:,c] * dZ[i, h, w, c]
1.5.1.2 - 计算 dW:¶

这是计算$dW_c$的公式 ($dW_c$ 是损失函数相对于一个filter的偏导数) :

$$ dW_c += \sum _{h=0} ^{n_H} \sum_{w=0} ^ {n_W} a_{slice} \times dZ_{hw} \tag{2}$$

其中$a_{slice}$被用来产生卷积操作输出$Z_{ij}$的slice。因此，这最终给了我们W对应于那个slice的梯度。因为它是相同的W，我们要把所有这样的梯度加起来，得到$dW$

编程时，在适当的for循环中，这个公式可以这样实现：

dW[:,:,:,c] += a_slice * dZ[i, h, w, c]
1.5.1.3 - 计算 db¶

对于一个给定的filter $W_{c}$，下面的公式用于计算代价函数相对于b的偏导数db：

$$ db = \sum_h \sum_w dZ_{hw} \tag{3}$$

之前在实现全联接网络的反向传播时，db 通过对dZ进行求和来得到。在CNN中，只需要把卷积层的输出Z的梯度dZ（代价函数相对于Z的偏导数）的所有元素加起来即可

编程时，在适当的for循环中，这个公式可以这样实现：

db[:,:,:,c] += dZ[i, h, w, c]

练习：实现函数conv_backward.我们应该遍历所有的训练样本，filters，高度和宽度。然后通过上述三个公式计算梯度。

def conv_backward(dZ, cache):
    """
    实现卷积层中卷积操作的反向传播

    Arguments:
    dZ -- 代价函数相对于卷积操作输出Z的偏导数, 四维数组(m, n_H, n_W, n_C)
    cache -- 前向传播中缓存的重要参数，用于与反向传播共享参数

    Returns:
    dA_prev -- 代价函数相对于卷积层的输入A_prev的偏导数，
               四维数组 (m, n_H_prev, n_W_prev, n_C_prev)
    dW -- 代价函数相对于卷积层权重参数的偏导数
          四维数组(f, f, n_C_prev, n_C)
    db -- 代价函数相对于卷积层偏置参数的偏导数
          四维数组 (1, 1, 1, n_C)
    """

    #取出卷积层前向传播缓存的参数
    (A_prev, W, b, hparameters) = cache

    #A_prev的相关信息
    (m, n_H_prev, n_W_prev, n_C_prev) = A_prev.shape

    #filters W的相关信息
    (f, f, n_C_prev, n_C) = W.shape

    #取出超参数
    stride = hparameters['stride']
    pad = hparameters['pad']

    #dZ的相关信息
    (m, n_H, n_W, n_C) = dZ.shape

    #初始化dA_prev,dW,db，数值设置为全0
    dA_prev = np.zeros((m, n_H_prev, n_W_prev, n_C_prev))
    dW = np.zeros((f, f, n_C_prev, n_C))
    db = np.zeros((1, 1, 1, n_C))

    #填充A_prev和dA_prev，全0填充
    A_prev_pad = zero_pad(A_prev, pad)
    dA_prev_pad = zero_pad(dA_prev, pad)

    for i in range(m): #遍历m张图像 （m个样本）
        a_prev_pad = A_prev_pad[i]
        da_prev_pad = dA_prev_pad[i]
        for h in range(n_H):#遍历每个输出图像垂直方向上的每个像素
            for w in range(n_W):#遍历每个输出图像水平方向上的每个像素
                for c in range(n_C):#遍历每个输出图像的每个通道
                     #找到每个图像各个区域的起始点
                    vert_start = h * stride
                    vert_end = vert_start + f
                    horiz_start = w * stride
                    horiz_end = horiz_start + f

                    #得到一个区域
                    a_prev_pad_slice = a_prev_pad[vert_start:vert_end, horiz_start:horiz_end, :]
                    da_prev_pad[vert_start:vert_end, horiz_start:horiz_end, :] += W[:, :, :, c] * dZ[i, h, w, c]
                    dW[:, :, :, c] += a_prev_pad_slice * dZ[i, h, w, c]
                    db[:, :, :, c] += dZ[i, h, w, c]
        dA_prev[i, :, :, :] = da_prev_pad[pad:-pad, pad:-pad, :]


    assert(dA_prev.shape == (m, n_H_prev, n_W_prev, n_C_prev))

    return dA_prev, dW, db

1.5.2.1 Max pooling 反向传播¶

在进行池化层反向传播之前，需要构建一个辅助函数 create_mask_from_window(),它的功能如下：

为什么要保留最大值的位置？因为这是一个最终影响输出值和cost的输入值。反向传播计算cost相对于每个参数的梯度，所以任何影响最终cost的东西都有一个非0梯度。所以，反向传播将传播梯度到影响cost的特定的输入值。

1.5.2.2 avg-pooling 反向传播¶

在max-pooling中，对于每一个输入窗口，对输出的所有影响都来自一个单一的输入值--最大值。在avg-pooling中，输入窗口的每一项对输出都有相同的影响。所以为了实现反向传播，需要先实现一个辅助函数反应上述过程：

对于每个样本，如果我们在前向传播中使用2*2的filter进行avg-pooling，那么你在反向传播中将使用的mask会是下面这样：

$$ dZ = 1 \quad \rightarrow \quad dZ =\begin{bmatrix} 1/4 && 1/4 \\ 1/4 && 1/4 \end{bmatrix}\tag{5}$$

这表示dZ矩阵中的每个位置对输出有同等的贡献，因为在前向传播中，我们取了平均。

练习:实现下面的函数，创建给定shape的矩阵均匀的分配值dz

def distribute_value(dz, shape):
    """
    用shape维的矩阵均匀的分配dz

    Arguments:
    dz -- 标量
    shape -- 均匀分配dz的矩阵的维度 (n_H,n_W)

    Returns:
    a -- 均匀分配dz的shape维的矩阵
    """

    (n_H, n_W) = shape
    a = np.ones(shape)
    a *= (dz / (n_H * n_W))

    return a

def pool_backward(dA, cache, mode = "max"):
    """
    实现池化层的反向传播

    Arguments:
    dA -- 代价函数cost相对于池化层输出A的梯度, 和 A同维
    cache -- 池化层前向传播过程中缓存的参数 包括池化层输入和超参数
    mode -- 模式 "max" or "average"

    Returns:
    dA_prev -- 代价函数cost相对于池化层输入A_prev的梯度, 和 A_prev同维
    """

    #取出cache中的参数
    (A_prev, hparameters) = cache

    #取出超参数
    f = hparameters['f']
    stride = hparameters['stride']

    #dA的相关信息
    (m, n_H, n_W, n_C) = dA.shape
    #A_prev 的相关信息
    (m, n_H_prev, n_W_prev, n_C_prev) = A_prev.shape

    #用0初始化dA_prev
    dA_prev = np.zeros(A_prev.shape)

    for i in range(m):                       # 遍历所有训练样本

        # 选择A_prev中的一个训练样本
        a_prev = A_prev[i]

        for h in range(n_H):#遍历每个输出图像垂直方向上的每个像素
            for w in range(n_W):#遍历每个输出图像水平方向上的每个像素
                for c in range(n_C):#遍历每个输出图像的每个通道
                     #找到每个图像各个区域的起始点
                    vert_start = h * stride
                    vert_end = vert_start + f
                    horiz_start = w * stride
                    horiz_end = horiz_start + f

                    #计算某个模式下的反向传播
                    if mode == "max":

                        # 使用之前的起始点和c定义a_prev的一个slice
                        a_prev_slice = a_prev[vert_start:vert_end, horiz_start:horiz_end, c]

                        # 为 a_prev_slice创建一个mask
                        mask = create_mask_from_window(a_prev_slice)

                        dA_prev[i, vert_start:vert_end, horiz_start:horiz_end, c] += dA[i, vert_start, horiz_start, c] * mask


                    elif mode == "average":

                        # 从dA中得到a
                        a = dA[i, vert_start, horiz_start, c]

                        shape = (f, f)

                        dA_prev[i, vert_start:vert_end, horiz_start:horiz_end, c] += distribute_value(a, shape)


    assert(dA_prev.shape == A_prev.shape)

    return dA_prev

2.2.3 前向传播¶

在TF中，下列内建函数可以帮助你构建卷积网络：

  • tf.nn.conv2d(X,W1, strides = [1,s,s,1], padding = 'SAME'): 给定一组输入样本 $X$(m, n_H_prev, n_W_prev, n_C_prev) 和一组 filters $W1$(f,f,n_C_prev,n_C),这个函数会用 $W1$中的 filters 对X进行卷积操作. 第三个参数 ([1,f,f,1]) 代表在输入X(m, n_H_prev, n_W_prev, n_C_prev)水平垂直两个维度上的步长都是f，该参数的第1和4维默认为1.

  • tf.nn.max_pool(A, ksize = [1,f,f,1], strides = [1,s,s,1], padding = 'SAME'): 给定一个输入 A(m, n_H_prev, n_W_prev, n_C_prev), 该函数将使用一个大小为 (f, f) 的窗口，在输入A的每个样本的每一个通道上，以一个步长 (s, s)对A进行池化操作 .

  • tf.nn.relu(Z1): 对卷积操作的输出Z1(m,n_H,n_W,n_C) (可以是任意形状)使用ReLU激活函数进行激活.

  • tf.contrib.layers.flatten(P): 给定一个输入 P(m,n_H,n_W,n_C), 该函数将其中的每个样本拉伸为一个1维 向量。 他将返回一个维度是 [batch_size, k]的tensor，作为最后全联接网络的输入.

  • tf.contrib.layers.fully_connected(F, num_outputs): 给定一个拉伸后的输入F，num_outputs定义全联接网络某层的单元数，返回一个经过全联接网络计算的输出.

最后一个函数 (tf.contrib.layers.fully_connected)定义一个全联接网络, 全联接网络的参数会自动初始化，并通过反向传播训练更新. 因此，在之前的初始化参数阶段，不用初始化这里的参数。

练习: 实现CNN模型的前向传播 forward_propagation 。

使用的CNN模型如下: CONV2D -> RELU -> MAXPOOL -> CONV2D -> RELU -> MAXPOOL -> FLATTEN -> FULLYCONNECTED. 使用上述函数实现.

统一使用如下的参数:

  • Conv2D: stride 1, padding is "SAME"
  • ReLU
  • Max pool: Use an 8 by 8 filter size and an 8 by 8 stride, padding is "SAME"
  • Conv2D: stride 1, padding is "SAME"
  • ReLU
  • Max pool: Use a 4 by 4 filter size and a 4 by 4 stride, padding is "SAME"
  • Flatten the previous output.
  • FULLYCONNECTED (FC) layer:只使用一个全联接层，即只有一个输出层，该层有6个单元，进行6分类，在前向传播时对该层不要使用softmax激活函数.在TF中计算cost和输出层的激活函数封装为了一个函数，在计算cost时同时对输出层使用softmax激活函数进行6分类。

    CONV2D -> RELU -> MAXPOOL -> CONV2D -> RELU -> MAXPOOL -> FLATTEN -> FULLYCONNECTED

    Arguments:
    X -- 输入数据的placeholder  维度 (None,n0_H,n0_W,n0_C)
    parameters -- Python字典包含模型的filters "W1", "W2"


    Returns:
    Z3 -- 最后前联接层（输出层）的线性单元的输出
    """

    W1 = parameters['W1']
    W2 = parameters['W2']

    ###请输入代码###

    #conv2d
    Z1 = tf.nn.conv2d(X, W1, strides=[1, 1, 1, 1], padding='SAME')
    #relu
    A1 = tf.nn.relu(Z1)
    #MAXpool
    P1 = tf.nn.max_pool(A1, ksize=[1, 8, 8, 1], strides=[1, 8, 8, 1], padding='SAME')
    #conv2d
    Z2 = tf.nn.conv2d(P1, W2, strides=[1, 1, 1, 1], padding='SAME')
    #relu
    A2 = tf.nn.relu(Z2)
    #maxpool
    P2 = tf.nn.max_pool(A2, ksize=[1, 4, 4, 1], strides=[1, 4, 4, 1], padding='SAME')
    #flattened
    F = tf.contrib.layers.flatten(P2)
    #FC
    Z3 = tf.contrib.layers.fully_connected(F, 6, activation_fn=None)

    ###请输入代码###

    return Z3

    CONV2D -> RELU -> MAXPOOL -> CONV2D -> RELU -> MAXPOOL -> FLATTEN -> FULLYCONNECTED
    
    Arguments:
    X_train -- 训练集样本 (None, 64, 64, 3)
    Y_train -- 训练集标签 (None, n_y = 6)
